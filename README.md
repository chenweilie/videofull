# 网页视频网页全屏 Chrome 插件 (Web Video Full Window)

这是一个专为 Chrome 浏览器设计的网页视频全屏扩展插件。它可以将网页上正在播放的视频瞬间放大至整个 Chrome 窗口宽度与高度（俗称“网页全屏”或“窗口全屏”），并智能隐藏网页的其它多余元素。

该插件非常适合**一边看视频一边进行多任务处理**（例如将浏览器窗口分屏放置，或放置在屏幕角落），而不需要像系统级全屏那样占用整个显示器。

## 💡 为什么开发此项目？

在日常使用电脑时，我们经常遇到这样的场景：
* **多任务协作需求**：在观看 **YouTube**、**Bilibili (哔哩哔哩)**、**IYF (独播库)** 等平台上的视频（如网课学习、技术讲座、体育赛事或游戏实况）时，我们往往需要同时开启其它窗口写代码、记笔记、查阅文档或与团队沟通。
* **现有播放模式的痛点**：
  1. **系统级全屏太霸道**：点击视频右下角的系统级“全屏”会直接占满整块屏幕，导致无法进行任何同屏多任务操作。
  2. **网页剧场模式不纯粹**：视频网站自身的“剧场模式”依然会在外围保留网页导航栏、右侧推荐列表、下方评论区以及滚动条等杂乱元素，极易令人分心，且浪费了宝贵的窗口空间。
  3. **画中画 (PIP) 存在局限**：浏览器自带的“画中画”模式虽然小巧，但**无法保留 Bilibili 等网站的弹幕**，也无法调用播放器原生的清晰度切换、外挂字幕或倍速设置。

**本插件正是为了终结这些痛点而生！** 

通过一键将播放器窗口完美放大至 100% 浏览器视口宽度与高度，并在后台彻底隐藏所有无关的侧边栏、推荐和评论，实现彻底的“净化”。让您可以把 Chrome 窗口缩放成任何大小、放置在屏幕任意角落，在不影响其它工作的同时，拥有一个毫无干扰、完美沉浸的看片体验。

## 🌟 核心功能

1. **智能播放器检测** (默认)：自动查找最外层的播放器容器（支持 YouTube、Bilibili 等主流网站及绝大多数自建播放器网站）。此模式下，**网站原生的弹幕、字幕、倍速、清晰度等控制栏会完美保留**，并自动贴合在窗口底部。
2. **纯视频画面模式**：仅放大 `<video>` 标签本身。在此模式下，控制栏会隐藏（需要时可点击右键显示浏览器默认控制栏），适合极简主义者。
3. **净化其它元素** (默认开启)：自动遍历视频节点的所有父辈和兄弟节点，隐藏一切无关元素，确保视频背景纯黑且无任何滚动条溢出。
4. **精美悬浮按钮**：鼠标悬停在视频上时，会在右上角自动浮现一个精美的毛玻璃特效控制图标，2.5 秒无操作后自动隐形，不遮挡视线。
5. **全局快捷键支持**：随时按下 `Alt + V` 即可快速切换网页全屏状态。
6. **防闪退与解耦**：监听 SPA 单页应用的路由切换及组件销毁，如视频播放完毕或页面切换，插件能自动恢复网页原本样式。
7. **高级毛玻璃弹窗与角标**：插件支持高颜值的 Glassmorphism 暗黑主题弹窗，且开启网页全屏时，插件图标会显示 `FULL` 蓝色角标，状态一目了然。

## 🛠️ 安装方法

由于是本地开发的 Chrome 插件，请按照以下步骤载入浏览器：

1. **下载或克隆代码**：确保该文件夹存在于你的本地（例如：`/Users/william/Project/Chrome/videofull`）。
2. **打开 Chrome 扩展管理页面**：
   - 在 Chrome 地址栏输入 `chrome://extensions/` 并回车。
   - 或者点击 Chrome 右上角菜单 -> “扩展程序” -> “管理扩展程序”。
3. **开启“开发者模式”**：
   - 切换扩展程序页面右上角的**“开发者模式”**开关（开启后会多出一排按钮）。
4. **载入扩展程序**：
   - 点击左上角的**“加载已解压的扩展程序” (Load unpacked)**。
   - 在弹出的文件选择框中，选择本插件对应的根文件夹（即包含 `manifest.json` 的目录，例如 `videofull`）。
5. **锁定插件**：
   - 点击 Chrome 右上角的扩展栏拼图图标 🧩，找到“网页视频全屏”，点击图钉图标 📌 将其固定在工具栏。

## 🚀 使用指南

### 方法一：悬浮按钮 (最直观)
- 打开任意包含视频的网页（例如 Bilibili 或 YouTube 视频播放页）。
- 鼠标移入视频画面，右上角会出现一个圆形的半透明展开图标。
- 点击它，视频即可平滑进入网页全屏！再度点击或按键盘 `Esc` 键退出。

### 方法二：键盘快捷键 (最高效)
- 在任何视频网页中，直接按下键盘快捷键：
  - **Windows / macOS**: `Alt + V`
- 视频将直接开启/关闭网页全屏。
- *如需更改快捷键，可点击插件弹出框底部的“修改快捷键”或直接在 Chrome 中打开 `chrome://extensions/shortcuts` 进行配置。*

### 方法三：插件弹出菜单 (最灵活)
- 点击 Chrome 工具栏上的插件图标，会弹出一个精致的主控台。
- 控制台会自动显示当前页面的视频检测状态（“已检测到网页播放的视频”）。
- 点击**“进入网页全屏”**即可激活。
- 你可以在控制台中随时切换“全屏目标模式”，或关闭“净化其它元素”及“悬浮控制按钮”。

## 📂 文件结构

```text
videofull/
├── manifest.json         # 插件配置文件 (Manifest V3)
├── background.js         # 后台服务脚本 (快捷键监听、角标管理)
├── content.js            # 网页内容脚本 (核心 DOM 操作、悬浮按钮生成)
├── content.css           # 网页全屏 CSS 覆盖样式、动画和毛玻璃效果
├── popup.html            # 插件控制台弹窗 HTML
├── popup.css             # 插件控制台弹窗 CSS (暗黑毛玻璃风格)
├── popup.js              # 插件控制台弹窗 JS (设置同步、状态监听)
└── icons/
    └── icon.svg          # 插件超清矢量图标
```

## 🔒 隐私与安全性

- **零数据收集**：本插件不收集、不上传任何个人数据或浏览历史。
- **本地存储**：你的配置参数（如模式选择、开关状态）仅保存在你本地的 Chrome 浏览器 Local Storage 中。
- **开源可信**：纯原生 JS 编写，不依赖任何第三方不可信的 CDN，保障网页加载速度和网络安全。
